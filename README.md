# FotoTurbo — lista de licenças canceladas

Este repositório guarda apenas o arquivo `canceladas.txt`: a lista, assinada digitalmente, dos códigos internos
das licenças do FotoTurbo que foram canceladas. O aplicativo FotoTurbo consulta este arquivo quando tem internet.

Não contém nomes, dados de clientes nem chaves. A lista é gerada e enviada pelo app "FotoTurbo Licenças";
qualquer alteração feita à mão invalida a assinatura e é ignorada pelo FotoTurbo.
